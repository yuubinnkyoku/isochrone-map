# 筑附高 08:20 等時線マップ

筑波大学附属高等学校の1限開始（08:20）に間に合うための最遅出発時刻を、等時線（isochrone）マップとして可視化するWebアプリケーション。

🌎 **[ページはこちら](https://yuubinnkyoku.github.io/isochrone-map/)**

## 高校版の算出条件

- 1限開始：**08:20**
- 校内移動などの余裕を2分取り、乗換検索上の学校到着基準：**08:18**
- Yahoo!乗換案内で到着地を **「筑波大学附属高等学校」** として施設直接指定
- 歩く速度：**「急いで」**
- 検索日：**2026-08-28（金）の平日ダイヤ**
- 路線バスは使用可、高速バスは使用不可
- 各駅名を文字列で検索するのではなく、国土数値情報 N02-25 の**物理駅地点の緯度経度を `flatlon` で固定**して検索
- Yahoo!乗換案内が提示する、その物理地点から最も遅く出発できる経路（ルート1）を採用
- 学校最寄り区間も手作業で徒歩時間を加算せず、Yahoo!乗換案内の施設までの徒歩経路をそのまま使用

## 収録駅

`data/stations.json` には **1563物理駅地点** を収録しています。これらは **1318論理駅** に対応します。

- 筑附高から直線距離50km以内について、国土数値情報の鉄道データ N02-25 の1322駅グループをすべてカバー
- 同じ乗換駅でも、路線別の代表座標が異なるものは**別々の物理駅地点**として保存・表示
- 完全に同一座標のN02駅コードだけを1点へまとめる
- 170論理駅が2点以上の物理駅地点を持つ
- 熊野前は「都電荒川線」と「日暮里・舎人ライナー」を別点として収録
- 東京は京葉線・新幹線・JR在来線・丸ノ内線などを別点として収録
- 武蔵小杉、池袋、両国なども路線設備の位置ごとに別点として収録
- 地下鉄と都電の早稲田、TX浅草と地下鉄・東武浅草のように元から別駅として扱うべき同名駅も引き続き分離
- ラベル優先度には国土数値情報「駅別乗降客数」S12-25（2024年、CC BY 4.0）を使用。事業者ごとに集計基準が異なるため、厳密な駅間比較ではなく表示優先度として利用

### 全1563地点の再計算監査

物理地点への分解後、1563地点すべてを同じ条件でYahoo!乗換案内に再問い合わせしました。

- 問い合わせ成功：**1563 / 1563**
- `flatlon` で指定した出発座標がYahoo側の徒歩経路開始点として5m以内に保持された地点：**1563 / 1563**
- 解析不能：**0**
- エラー：**0**
- 最初の鉄道乗車がその物理地点自身：976地点
- 同じ論理駅の別物理地点へ歩いてから乗車：232地点
- 別の駅へ移動してから乗車：343地点
- 最適経路で鉄道に乗らない：12地点

旧データでは「駅名検索の直接値」と「その地点から歩いて別経路を使う値」が食い違う場合に、直接値をIDW補間から除外していました。新データでは**最初から各物理座標そのものを出発地として最適経路を再計算**しているため、別駅・別構成駅へ歩いてから乗る場合もその地点の正しいアクセシビリティ値です。そのため、1563地点すべてをIDW標本として使用します。

## 主な機能

- **等時線表示**: 3分 / 5分 / 10分間隔で最遅出発時刻の等時線を描画
- **グラデーション表示**: 最遅出発時刻を連続的に色分け
- **3D表示**: 補間した時刻を地形状に表示
- **事前計算IDWグリッド**: 1563物理駅地点とのIDW補間を更新時に `scripts/build_precomputed_grid.mjs` で約100m間隔の静的グリッドへ変換し、ブラウザでは双線形補間のみ実行
- **物理駅地点表示**: 同じ乗換駅でも離れたホーム・路線設備は別マーカー。十分拡大すると各物理地点のラベルを表示
- **論理駅検索**: 「池袋」のような論理駅名でも、「池袋（副都心線）」のような物理地点名でも検索可能
- **早朝・前日発への対応**: 06:30以前は1時間刻みの等時線を描画し、前日発は「前日HH:MM」として扱う
- **地図切替**: 国土地理院・OpenStreetMapなど
- **距離比較**: 筑附高を中心とする5km・10km・15km・20km・30km・40km・50km円
- **駅名ラベル**: 縮小時は代表地点のみ、中間ズームでは乗降客数優先、十分拡大すると全物理地点を表示
- **ダークモード**

高校には中学版の市区町村ベースの学区境界を適用しないため、旧学区表示機能・学区データ・中学版専用の一時データ生成スクリプトは削除しています。

## 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **地図描画**: Leaflet.js
- **3D表示**: Three.js
- **補間**: IDW（逆距離加重）
- **等時線生成**: マーチングスクエア法

## 駅データ更新時の注意

`stations.json` の `meta.targetArrival` は **08:18**、`meta.targetMinutes` は **498** です。時刻を更新するときは、全物理地点を同じ検索日・同じYahoo!乗換案内条件で再監査し、`minutes`・`route`・`duration`・`searchDate` を揃えて更新します。

東京23区および筑附高から直線距離50km以内の駅母集団は国土数値情報 N02-25 を基準にしています。駅名だけで同一性を決めず、N02の駅グループ・路線別駅コード・座標を保持します。

### IDWグリッドの再生成

駅の `minutes` や座標を変更した場合は、駅データ更新後に次を実行します。

```bash
node scripts/build_precomputed_grid.mjs
```

`data/idw-grid.bin`、`data/idw-grid.bin.gz`、`data/idw-grid.meta.json` が再生成されます。通常のブラウザはgzip版を読み込み、非対応環境のみ非圧縮版へフォールバックします。グリッドは駅群の外側に約0.6度の余白を取り、緯度経度0.001度（東京付近で約90〜110m）間隔でIDWを事前計算しています。値は0.01分単位の16bit整数として保存し、表示時は4近傍から双線形補間します。これによりパン・ズームのたびに全駅を走査する必要がありません。
