# 筑附高 08:20 等時線マップ

筑波大学附属高等学校の1限開始（08:20）に間に合うための最遅出発時刻を、等時線（isochrone）マップとして可視化するWebアプリケーション。

🌎 **[ページはこちら](https://yuubinnkyoku.github.io/isochrone-map/)**

## 高校版の算出条件

- 1限開始：**08:20**
- 校内移動などの余裕を2分取り、乗換検索上の学校到着基準：**08:18**
- Yahoo!乗換案内で到着地を **「筑波大学附属高等学校」** として施設直接指定
- 歩く速度：**「急いで」**
- 検索日：**2026-08-28（金）の平日ダイヤ**
- Yahoo!乗換案内が提示する最も遅く出発できる経路（ルート1）を採用
- 学校最寄り区間も手作業で徒歩時間を加算せず、Yahoo!乗換案内の施設までの徒歩経路をそのまま使用

## 収録駅

`data/stations.json` には **1318駅** を収録しています。

- 従来データと東京23区全駅データを統合し、重複していた浮間舟渡を1駅に整理
- 東京23区については、国土数値情報の鉄道データ（N02-25）と2026年行政区域データを用いて区内駅を抽出し、未収録395駅を追加
- 筑附高から直線距離50km以内についても N02-25 の駅グループを基準に再照合し、圏内1322グループをすべてカバー（50kmへの拡張で不足していた170駅を追加）
- 西武園ゆうえんち駅のみ、当日朝の始発では08:18までに到着できないため、Yahoo!到着指定で得られる前日22:31発を記録し、地図上の色は凡例下限（06:30以前）として表示
- JR・私鉄・東京メトロ・都営地下鉄に加え、都電荒川線、日暮里・舎人ライナー、ゆりかもめ、東京モノレールなども対象
- 東京駅や池袋駅のように同一駅の設備が離れている場合は1駅に統合
- 地下鉄と都電の早稲田駅、TX浅草駅と地下鉄・東武浅草駅のように実質別駅のものは分けて収録
- ラベル優先度には国土数値情報「駅別乗降客数」S12-25（2024年、CC BY 4.0）を使用。事業者ごとに集計基準が異なるため、厳密な駅間比較ではなく表示優先度として利用

## 主な機能

- **等時線表示**: 3分 / 5分 / 10分間隔で最遅出発時刻の等時線を描画
- **グラデーション表示**: 最遅出発時刻を連続的に色分け
- **3D表示**: 補間した時刻を地形状に表示
- **事前計算IDWグリッド**: 1318駅とのIDW補間は更新時に `scripts/build_precomputed_grid.mjs` で約100m間隔の静的グリッドへ変換し、ブラウザでは双線形補間のみ実行
- **前日発の可視化**: 06:30以前は1時間刻みの等時線を描画し、前日発になる地点は「前日HH:MM」として表示
- **地図切替**: 国土地理院・OpenStreetMapなど
- **距離比較**: 筑附高を中心とする5km・10km・15km・20km・30km・40km・50km円
- **駅検索・駅名ラベル**: 縮小時は主要駅のみ、中間ズームでは国土数値情報「駅別乗降客数」（2024年）の上位駅から段階表示し、十分拡大すると全駅を表示
- **ダークモード**

高校には中学版の市区町村ベースの学区境界を適用しないため、旧学区表示機能・学区データ・中学版専用の一時データ生成スクリプトは削除しています。

## 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **地図描画**: Leaflet.js
- **3D表示**: Three.js
- **補間**: IDW（逆距離加重）
- **等時線生成**: マーチングスクエア法

## 駅データ更新時の注意

`stations.json` の `meta.targetArrival` は **08:18**、`meta.targetMinutes` は **498** です。時刻を更新するときは、各駅の `minutes`・`route`・`duration`・`searchDate` を同じ検索日・同じYahoo!乗換案内条件で揃えて更新します。

東京23区および筑附高から直線距離50km以内の駅母集団は国土数値情報を基準にしています。同名駅については座標を照合し、別地域の同名駅をYahoo!乗換案内が選択していないことを確認します。

駅別乗降客数は `python3 scripts/update_passenger_counts.py` で国土数値情報 S12-25 を取得・照合して更新できます。2024年値がない駅は推定せず `null` とし、利用者数による中間ズームの優先表示対象から外します。


### IDWグリッドの再生成

駅の `minutes` や座標を変更した場合は、駅データ更新後に次を実行します。

```bash
node scripts/build_precomputed_grid.mjs
```

`data/idw-grid.bin`、`data/idw-grid.bin.gz`、`data/idw-grid.meta.json` が再生成されます。通常のブラウザはgzip版を読み込み、非対応環境のみ非圧縮版へフォールバックします。グリッドは駅群の外側に約0.6度の余白を取り、緯度経度0.001度（東京付近で約90〜110m）間隔でIDWを事前計算しています。値は0.01分単位の16bit整数として保存し、表示時は4近傍から双線形補間します。これによりパン・ズームのたびに全駅を走査する必要がありません。
