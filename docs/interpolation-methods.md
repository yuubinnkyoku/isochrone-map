# 補間方法

駅マーカーの時刻は、1563個の物理駅地点それぞれについて Yahoo!乗換案内の `flatlon` で座標を固定し、08:18までに筑波大学附属高等学校へ着ける最遅出発時刻を再検索した値です。

地図上の駅と駅の間は直接検索していないため、表示時には事前計算グリッドから補間します。現在は2方式を切り替えられます。

## 補間標本

鉄道駅だけで補間すると、目的地である学校そのものに既知の境界条件が入りません。そこで両方式とも、1563物理駅地点に加えて**筑波大学附属高等学校そのものを08:18（498分）の補間専用アンカー**として追加します。

- 物理駅地点: 1563点
- 学校の目的地アンカー: 1点
- 補間標本の合計: 1564点

学校アンカーは駅マーカーではなく、`data/interpolation-anchors.json` に独立して保存します。学校の座標は `35.716741, 139.7308823`、値は検索上の学校到着基準 `08:18` です。したがって補間の元関数では、学校地点そのものが既知値08:18を持ちます。

## 徒歩アクセス考慮（デフォルト）

まずIDWで1564標本を滑らかにつないだ値 `IDW(x)` を求め、その地点から**最寄りの補間アンカーまでの徒歩アクセス時間**を明示的に差し引きます。最寄りアンカーには物理駅だけでなく学校自身も含みます。

```text
T(x) = IDW(x) - 1.25 * d_nearest_anchor(x) / 80
```

- `d_nearest_anchor(x)`: 地点から最寄りの物理駅または学校アンカーまでの直線距離（m）
- `80`: 徒歩速度 80 m/分（急ぎ足の近似）
- `1.25`: 道路が直線ではないことを近似する迂回係数
- 実効的には直線距離 64 m/分、約 3.84 km/h 相当の減衰

従来IDWだけの場合は、駅から離れても「駅まで行く時間」が式に入っていません。この補正を加えることで、駅の密度や周囲の駅時刻が同程度なら、駅から遠い場所ほど明示的に不利になります。学校付近では学校アンカーまでの距離が0へ近づくので、目的地直前で不自然に時刻が早まるのも防ぎます。

### なぜ `max_i(t_i - 徒歩時間)` にしないか

当初は各駅の時刻から徒歩時間を引き、その最大値を取る max-plus 型も検証しました。しかし、直線距離×固定迂回係数では河川・線路・山・駅入口などの障害を完全には表現できません。そのため高尾山などで、**既にYahoo exact-pointで検索済みの駅地点そのものに、別駅からの近似徒歩候補が約9分も上回る**ケースが生じました。

既知の駅地点の値より近似モデルを優先するのは不適切なので、採用していません。現在の方式は既存IDWを基準にし、最寄りアンカーから離れることによる追加の不利だけを与える、より保守的な補間です。

これは歩行者経路探索そのものではありません。河川、線路、崖、道路網、駅入口位置などを個別には考慮せず、直線距離に固定の迂回係数を掛けた近似です。駅マーカーの値はYahoo exact-point再検索値をそのまま表示し、このモデルは面表示だけに使います。

事前計算は `scripts/build_access_grid.mjs` が行い、学校アンカーを含む `idw-grid` を基準にKD-treeで各グリッド点の最寄り補間アンカー距離を求め、`data/access-grid.bin(.gz)` を生成します。

## 従来IDW

従来方式は Web Mercator 上の距離による逆距離加重平均です。現在の「従来IDW」表示にも学校アンカーは含めます。つまり「徒歩減点をしない旧来の補間式」という意味であり、目的地の既知値を捨てる比較ではありません。

```text
IDW(x) = sum_i w_i(x) t_i / sum_i w_i(x)
w_i(x) = 1 / d(x, i)^2.5
```

駅地点の時刻を滑らかにつなぐには向いていますが、「駅から500m離れれば徒歩時間ぶん不利になる」という意味は持ちません。比較・検証用として残しています。

## 表示との関係

「最適経路でこの地点の鉄道を使わない駅」の中抜き/強調表示と、補間方式は独立です。

- 駅マーカー: 1563物理駅地点の exact-point Yahoo! 再検索値
- 学校アンカー: 補間専用の既知値08:18。駅マーカーとしては追加しない
- 中抜き等: その物理地点の鉄道を最適経路で使うかどうか
- 徒歩アクセス考慮: 学校を含むIDW面から、最寄り補間アンカーまでの近似徒歩時間を減算
- 従来IDW: 学校を含む1564標本を距離加重平均

駅のIDW採否を変更するものではなく、1563物理駅地点は両方式の基礎データとしてすべて保持します。
